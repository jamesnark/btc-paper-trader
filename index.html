How to read this
  • Calls right: how often the model's direction (Up if it says over 50%) matched the result, across every window. 50% is a coin flip.
  • Bets: the model only bets when its probability beats the price plus Polymarket's fee (0.07 × price × (1 − price) per share) by at least 1¢. At 51¢ you need to win about 52.8% just to break even.
  • ± margin: the 95% "could be luck" range. If 50% is inside it, you can't tell the model from a coin flip yet. It shrinks as more windows come in.
  • Kelly: the math-optimal bet size for the edge the model claims. Half Kelly is what most pros use because models are usually overconfident. Betting more than 2x Kelly (like 75% every bet) loses money long-term even with a real edge.
  • Live vs backtest: live uses the real order book at the moment of the decision. The backtest replays past windows using recorded prices plus half a cent, and decides 10 minutes before each window starts. Trust live more.
  • To try a new idea, edit model.js in the repo. The next run picks it up automatically.

Data: Polymarket public API (prices, results), Coinbase (BTC candles). Educational simulator only.
